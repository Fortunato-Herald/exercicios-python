## 📌 Sobre o projeto

Este repositório contém uma **lista progressiva de exercícios em Python**, focada em **estruturas sequenciais**, ideal para quem está iniciando na programação e quer evoluir até um nível mais avançado.

Os exercícios estão organizados por nível de dificuldade:

- 🟢 Básico
- 🟡 Intermediário
- 🔴 Avançado

---

## 🎯 Objetivo

- Desenvolver lógica de programação  
- Praticar operações matemáticas  
- Trabalhar com entrada e saída de dados  
- Preparar base para Data Science e desenvolvimento
